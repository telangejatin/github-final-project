# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for everyone.

## Expected Behavior

- Be respectful and considerate.
- Use inclusive and welcoming language.
- Accept constructive feedback.
- Focus on what is best for the community.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, or other inappropriate behavior will not be tolerated.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.
